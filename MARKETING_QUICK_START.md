# Marketing Quick Start Checklist

## Week 1: Foundation Setup

### Day 1-2: Google Business Profile

- [ ] Claim/verify Google Business Profile
- [ ] Add complete business information
- [ ] Upload 20+ high-quality photos
- [ ] Add services, hours, attributes
- [ ] Enable messaging
- [ ] Respond to any existing reviews

### Day 3-4: Technical SEO

- [ ] Verify Google Search Console
- [ ] Create and submit sitemap.xml
- [ ] Add LocalBusiness schema markup
- [ ] Add Service schema markup
- [ ] Add Review schema markup
- [ ] Optimize robots.txt

### Day 5-7: Lead Magnets

- [ ] Create "Complete Guide to Home Staging" PDF (20-30 pages)
- [ ] Create staging checklist PDF
- [ ] Set up email capture forms
- [ ] Design landing pages for lead magnets

## Week 2: Content & Setup

### Content Creation

- [ ] Write 2 blog posts:
  - "How Much Does Home Staging Cost in San Francisco?"
  - "Complete Guide to Home Staging ROI"
- [ ] Create social media content calendar (30 days)
- [ ] Design 10 social media graphics

### Tools Setup

- [ ] Set up email marketing platform (Mailchimp/ConvertKit)
- [ ] Set up Google Analytics 4
- [ ] Install Facebook Pixel
- [ ] Set up call tracking
- [ ] Install heat mapping tool (Hotjar)

## Week 3: Paid Advertising

### Google Ads

- [ ] Create Google Ads account
- [ ] Set up first campaign ($1,000/month budget)
- [ ] Create 3 ad groups with 3-5 keywords each
- [ ] Write 3 ad variations per ad group
- [ ] Create dedicated landing page
- [ ] Set up conversion tracking

### Facebook Ads

- [ ] Create Facebook Business Manager account
- [ ] Set up Facebook Pixel
- [ ] Create first lead gen campaign ($500/month)
- [ ] Design 5 ad creatives
- [ ] Set up retargeting audience

## Week 4: Optimization

### Website Improvements

- [ ] Add prominent CTA to homepage
- [ ] Add trust signals (reviews, partner logos)
- [ ] Add exit-intent popup
- [ ] Add live chat widget
- [ ] Create city-specific landing pages (start with 3)

### Content

- [ ] Publish 2 blog posts
- [ ] Create first video (before/after tour)
- [ ] Set up email welcome series
- [ ] Launch first newsletter

## Month 2: Scale & Optimize

- [ ] Increase ad budgets based on performance
- [ ] Create 2 more blog posts
- [ ] Launch agent partnership program
- [ ] Create case study page
- [ ] Set up monthly reporting dashboard

## Quick Wins You Can Do Today

1. **Google Business Profile** (30 minutes)

   - Claim and optimize your profile
   - Add photos and services

2. **Add Schema Markup** (1 hour)

   - Add LocalBusiness schema to homepage
   - Add Review schema to reviews section

3. **Create Lead Magnet** (2-3 hours)

   - Write "10 Staging Mistakes to Avoid" guide
   - Create simple PDF
   - Add email capture form

4. **Social Media** (30 minutes)

   - Post before/after photo on Instagram
   - Share on Facebook
   - Post on LinkedIn

5. **Email List** (1 hour)
   - Set up Mailchimp account
   - Create welcome email
   - Add signup form to website

## Budget-Friendly Options

If budget is limited, focus on:

1. **SEO** (Free, but time-intensive)
2. **Google Business Profile** (Free)
3. **Content Marketing** (Low cost, high ROI)
4. **Email Marketing** (Low cost, high ROI)
5. **Social Media** (Free, but time-intensive)

Start with $500-1,000/month for Google Ads, then scale as you see results.
